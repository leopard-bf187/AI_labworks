# Лабораторная работа №3 — алгоритм Boids

**Дисциплина:** Искусственный интеллект  
**Тема:** Моделирование коллективного поведения агентов (Boids)  
**Приложение:** GPUBoids — C++, Direct3D 11, HLSL  
**Результат:** лабораторная работа выполнена и защищена.

## 1. Цель работы

Изучить алгоритм **Boids** для моделирования коллективного движения автономных агентов, рассмотреть основные правила взаимодействия и реализовать их демонстрацию в трёхмерном пространстве.

Для выполнения работы использован демонстрационный пример **Microsoft GPUBoids**, адаптированный с Direct3D 10 на **Direct3D 11**, **DXUT11**, **Effects11** и **DirectXMath**. Математическая модель поведения сохранена, ключевые участки кода снабжены комментариями.

## 2. Теоретические сведения

Boids — модель, в которой согласованное поведение роя возникает из совокупности управляющих воздействий на каждого агента.

### 2.1. Основные правила

| Правило | Назначение | Функция в `GPUBoids.fx` |
| --- | --- | --- |
| **Separation** (разделение) | Отталкивание от других агентов для уменьшения скученности | `Separation()` |
| **Alignment** (выравнивание) | Согласование направления движения с группой | `Alignment()` |
| **Cohesion** (сплочение) | Стремление к центру группы | `Cohesion()` |

В этой реализации дополнительно используются:

- **Seek** — движение к заданной позиции (`Seek()`).
- **Flee** — удаление от управляемого шара (`Flee()`).
- **Avoid** — уклонение от других агентов с учётом текущего направления движения (`Avoid()`).

Важная особенность: для **Cohesion** и **Alignment** в данном проекте применяются приближённые средние значения положения и скорости **всего роя**, рассчитанные через mipmap, а не локальный поиск соседей в заданном радиусе. Для **Separation** и **Avoid** рассчитываются попарные взаимодействия.

### 2.2. Расчёт управляющей силы

В `PSAdvance()` результирующая сила формируется как взвешенная сумма:

```text
F = w_separation * (F_separation + F_avoid)
  + w_seek       * F_seek
  + w_cohesion   * F_cohesion
  + w_alignment  * F_alignment
  + w_flee       * F_flee
```

Модуль силы ограничивается значением `g_fMaxForce`. Затем обновляются скорость, положение и ориентация агента:

```text
velocity_new = velocity + acceleration * dt
position_new = position + velocity * dt
```

В исходной реализации положение рассчитывается по **старой** скорости, а при сохранении новой скорости её модуль принудительно устанавливается равным `g_fMaxSpeed`. Эти особенности не изменялись в рамках адаптации проекта.

## 5. Реализация

### 5.1. Хранение состояния агентов

Приложение моделирует **4096** агентов (`MAX_PARTICLES = 4096`).

Состояние каждого агента хранится не в отдельном объекте C++, а в текстурах `Texture2DArray` на GPU. Используются три слоя:

1. **Position** — трёхмерные координаты агента.
2. **Velocity** — направление движения и модуль скорости.
3. **Up** — вектор ориентации модели.

Создаются две текстуры состояния: **From** и **To**. При каждом обновлении одна используется для чтения, другая — для записи. После завершения прохода `SwapParticleTextures()` меняет их местами. Этот механизм называется **ping-pong buffering**.

Отдельная `g_pForceTexture` служит для накопления попарных сил взаимодействия.

### 5.2. Этапы кадра

Основная последовательность выполняется в `OnD3D11FrameRender()`:

| Этап | Функция | Результат |
| --- | --- | --- |
| 1 | `GenerateMips()` | Приближённое усреднение положений и скоростей агентов |
| 2 | `AccumulateForces()` или `AccumulateForcesGS()` | Вычисление `Separation + Avoid` и накопление сил |
| 3 | `AdvanceParticles()` | Расчёт нового состояния в `PSAdvance()` |
| 4 | `SwapParticleTextures()` | Обмен входной и выходной текстур |
| 5 | `RenderMeshInstanced()` | Отрисовка экземпляров моделей Boids |

Накопление сил реализовано в двух вариантах. В одном экранные квадраты создаёт geometry shader, в другом используются заранее подготовленные треугольники. При этом оба варианта вызывают `PSForce()`, а вклады суммируются аддитивным смешиванием.

### 5.3. Основные участки шейдерного кода

В [`GPUBoids.fx`](GPUBoids.fx) находятся следующие функции:

| Функция | Назначение |
| --- | --- |
| `Separation()` | Рассчитывает отталкивание от другого агента |
| `Alignment()` | Формирует воздействие для согласования движения |
| `Cohesion()` | Формирует воздействие в сторону центра роя |
| `Seek()` | Создаёт силу движения к заданной точке |
| `Flee()` | Создаёт силу удаления от шара |
| `Avoid()` | Создаёт дополнительную силу уклонения |
| **`PSForce()`** | Рассчитывает взаимодействия между агентами |
| **`PSAdvance()`** | Складывает силы и обновляет состояние |
| `VSBoids()` | Размещает модели по полученным координатам |

Таким образом, **математика алгоритма Boids выполняется преимущественно на GPU**, а C++ управляет ресурсами и порядком проходов.

### 5.4. Отрисовка

Для отображения используется модель `Media/GPUBoids/boid.sdkmesh`. Вместо отдельного draw call на каждого агента вызывается `DrawIndexedInstanced()`, что позволяет рисовать множество экземпляров одной модели.

В `VSBoids()` системный параметр `SV_InstanceID` определяет индекс агента, после чего шейдер считывает из текстуры его позицию и ориентацию.

Также отображается шар `Media/misc/ball.sdkmesh`. Изменение его координат влияет на силу `Flee`, благодаря чему можно визуально наблюдать реакцию роя на перемещаемый объект.

## 7. Выполненная адаптация исходного примера

В ходе работы выполнены следующие изменения:

1. Перенос приложения с **Direct3D 10 на Direct3D 11**.
2. Подключение **DXUT11** и **Effects11**, обновление API работы с устройством, контекстом и шейдерными техниками.
3. Замена математических типов и операций D3DX на **DirectXMath**.
4. Адаптация загрузки моделей и инстансированного рендеринга.
5. Добавление комментариев к алгоритму Boids и этапам GPU-симуляции.
6. Добавление диагностических сообщений при ошибках компиляции HLSL и инициализации ресурсов.
7. Устранение ошибки `Illegal character in shader file` путём удаления BOM из `GPUBoids.fx`.
8. Исправление получения матриц `View` и `Projection` из камеры после перехода на DirectXMath.

При этом принципы вычисления управляющих сил, структура GPU-проходов и алгоритм Boids сохранены.

## 8. Сборка и запуск

1. Открыть `GPUBoids.sln` в Visual Studio с установленными средствами разработки C++ и Windows SDK.
2. Проверить доступность используемого в файле проекта toolset **v142** либо перенастроить его на установленную версию.
3. Выбрать конфигурацию `Debug` или `Release` и собрать приложение.
4. Убедиться в доступности `GPUBoids.fx` и ресурсов каталога `Media/` (их поиск выполняется через DXUT).
5. Запустить `GPUBoids.exe`.

Исходники DXUT11 и Effects11 включены в репозиторий. Для компиляции шейдеров используется библиотека `d3dcompiler.lib`; настройки зависимостей указаны в проекте Visual Studio.

## 9. Результаты

В результате получено приложение с трёхмерной визуализацией роя, в котором:

- моделируется поведение **4096 агентов**;
- на GPU вычисляются силы взаимодействия и обновляются параметры движения;
- используется хранение состояния в текстурах и схема ping-pong;
- множество моделей выводится методом instanced rendering;
- пользователь может перемещать шар и наблюдать изменение поведения роя;
- предусмотрено переключение двух вариантов накопления сил.

После исправления ошибок инициализации и передачи матриц приложение успешно запустилось, а Boids отображались и двигались в сцене. **Лабораторная работа была продемонстрирована преподавателю и успешно защищена.**

**Ограничения реализации:** демонстрация не содержит конечного автомата задач, отдельной системы поиска пути или полноценного обхода препятствий произвольной сцены. Профилирование GPU и численные измерения FPS в данном отчёте не приводятся.

## 10. Вывод

В лабораторной работе изучены принципы алгоритма Boids: разделение, выравнивание и сплочение, а также дополнительные управляющие силы притяжения и избегания.

На основе проекта GPUBoids рассмотрены реализация коллективного поведения на GPU, хранение данных агентов в текстурах, выполнение нескольких последовательных шейдерных проходов и визуализация роя методом instancing.

Практическим результатом стала работающая демонстрация на **Direct3D 11** с документированными ключевыми этапами расчёта Boids.
