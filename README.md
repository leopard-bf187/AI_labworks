## 2. Постановка задачи

Необходимо разработать программное решение, реализующее детерминированный конечный автомат для распознавания слов формального языка согласно выбранному варианту.

Автомат должен последовательно обрабатывать каждый символ входного слова и после завершения анализа определить, принадлежит ли слово заданному языку.

Для реализации используется язык программирования **C++17**. Сборка проекта выполняется с помощью **CMake**.

## 3. Индивидуальный вариант

Выбран **вариант №18**:

```text
aⁿbᵐcᵏ
```

Ограничения:

```text
n >= 1
m >= 2
k >= 3

n — чётное
m — чётное
k делится на 3
```

Формально язык можно записать следующим образом:

```text
L = { aⁿbᵐcᵏ | n >= 1, m >= 2, k >= 3,
      n mod 2 = 0,
      m mod 2 = 0,
      k mod 3 = 0 }
```

Поскольку `n` должно одновременно быть не меньше единицы и быть чётным, минимально возможное значение `n` равно `2`.

Аналогично:

```text
n_min = 2
m_min = 2
k_min = 3
```

Следовательно, минимальное слово языка:

```text
aabbccc
```

Примеры корректных слов:

```text
aabbccc
aaaabbccc
aabbbbccc
aabbcccccc
aaaabbbbcccccc
```

Примеры некорректных слов:

```text
abbccc
aabbbccc
aabbcc
aabbcccc
aacc
bbaaccc
```

## 4. Теоретические сведения

Детерминированный конечный автомат задаётся пятёркой:

```text
M = (Q, Σ, δ, q0, F)
```

где:

- `Q` — конечное множество состояний;
- `Σ` — входной алфавит;
- `δ` — функция переходов;
- `q0` — начальное состояние;
- `F` — множество допускающих состояний.

Особенность детерминированного конечного автомата заключается в том, что для каждой пары:

```text
(текущее состояние, входной символ)
```

существует ровно один определённый переход, если учитывать ошибочное состояние.

В данной работе дополнительная память и числовые счётчики не используются. Информация о чётности количества символов и остатке от деления хранится непосредственно в состоянии автомата.

---

## 5. Формальное описание разработанного автомата

### 5.1. Входной алфавит

Используется алфавит:

```text
Σ = { a, b, c }
```

Любой другой символ приводит автомат в ошибочное состояние.

### 5.2. Множество состояний

Автомат содержит следующие состояния:

| Состояние | Назначение |
|---|---|
| `Start` | Начальное состояние |
| `AOdd` | Прочитано нечётное количество символов `a` |
| `AEven` | Прочитано чётное количество символов `a` |
| `BOdd` | Начат блок `b`, прочитано нечётное количество `b` |
| `BEven` | Прочитано чётное количество символов `b` |
| `CMod1` | Количество `c` даёт остаток `1` при делении на `3` |
| `CMod2` | Количество `c` даёт остаток `2` при делении на `3` |
| `CMod0` | Количество `c` делится на `3` |
| `Error` | Ошибочное состояние |

Таким образом:

```text
Q = { Start, AOdd, AEven, BOdd, BEven, CMod1, CMod2, CMod0, Error }
```

Начальное состояние:

```text
q0 = Start
```

Множество допускающих состояний:

```text
F = { CMod0 }
```

## 6. Таблица переходов

| Текущее состояние | `a` | `b` | `c` |
|---|---|---|---|
| `Start` | `AOdd` | `Error` | `Error` |
| `AOdd` | `AEven` | `Error` | `Error` |
| `AEven` | `AOdd` | `BOdd` | `Error` |
| `BOdd` | `Error` | `BEven` | `Error` |
| `BEven` | `Error` | `BOdd` | `CMod1` |
| `CMod1` | `Error` | `Error` | `CMod2` |
| `CMod2` | `Error` | `Error` | `CMod0` |
| `CMod0` | `Error` | `Error` | `CMod1` |
| `Error` | `Error` | `Error` | `Error` |

Все переходы однозначны, следовательно, автомат является детерминированным.

## 7. Схема автомата

Упрощённая схема:

```text
Start --a--> AOdd --a--> AEven
              ^            |
              |            |
              +----- a ----+

AEven --b--> BOdd --b--> BEven
              ^            |
              |            |
              +----- b ----+

BEven --c--> CMod1 --c--> CMod2 --c--> CMod0
              ^                            |
              |                            |
              +------------ c -------------+
```

Все неуказанные переходы ведут в состояние:

```text
Error
```

Единственным допускающим состоянием является:

```text
CMod0
```

---

## 8. Принцип работы автомата

### 8.1. Обработка блока `a`

Первый символ `a` переводит автомат:

```text
Start -> AOdd
```

Второй символ:

```text
AOdd -> AEven
```

Каждый последующий символ `a` переключает состояния:

```text
AOdd <-> AEven
```

Переход к блоку `b` возможен только из `AEven`. Поэтому количество `a` обязательно является чётным.

---

### 8.2. Обработка блока `b`

Первый символ `b` переводит автомат:

```text
AEven -> BOdd
```

Второй:

```text
BOdd -> BEven
```

Последующие символы `b` переключают состояния:

```text
BOdd <-> BEven
```

Перейти к блоку `c` можно только из `BEven`.

Поэтому количество `b` должно быть чётным. Для достижения `BEven` необходимо прочитать как минимум два символа `b`, что автоматически обеспечивает условие `m >= 2`.

---

### 8.3. Обработка блока `c`

После завершения блока `b` первый символ `c` переводит автомат:

```text
BEven -> CMod1
```

Далее выполняются переходы:

```text
CMod1 --c--> CMod2
CMod2 --c--> CMod0
CMod0 --c--> CMod1
```

Состояния соответствуют остатку от деления количества символов `c` на `3`.

Состояние `CMod0` достигается после:

```text
3, 6, 9, 12, ...
```

символов `c`.

Следовательно, автомат принимает слово только тогда, когда количество `c` делится на `3`.

---

## 9. Алгоритм программы

Работа программы состоит из следующих этапов:

1. Создаётся объект класса `FiniteAutomaton`.
2. Пользователь вводит слово.
3. Состояние автомата устанавливается в `Start`.
4. Каждый символ строки последовательно передаётся функции `Transition`.
5. Функция определяет следующее состояние автомата.
6. При невозможном переходе автомат попадает в состояние `Error`.
7. После обработки всей строки проверяется текущее состояние.
8. Если автомат находится в `CMod0`, слово принимается.
9. Во всех остальных состояниях слово отклоняется.

Основные функции программы:

```cpp
bool Recognize(const std::string& word) const;
State Transition(State state, char character) const;
bool IsAcceptingState(State state) const;
```

## 11. Исходный код программы

Файл `src/main.cpp`:

```cpp
#include <iostream>
#include <string>

enum class State
{
    Start,

    AOdd,
    AEven,

    BOdd,
    BEven,

    CMod1,
    CMod2,
    CMod0,

    Error
};

class FiniteAutomaton
{
public:
    bool Recognize(const std::string& word) const
    {
        State state = State::Start;

        for (char character : word)
        {
            state = Transition(state, character);

            if (state == State::Error)
                return false;
        }

        return IsAcceptingState(state);
    }

private:
    State Transition(State state, char character) const
    {
        switch (state)
        {
            case State::Start:
            {
                if (character == 'a')
                    return State::AOdd;

                return State::Error;
            }

            case State::AOdd:
            {
                if (character == 'a')
                    return State::AEven;

                return State::Error;
            }

            case State::AEven:
            {
                if (character == 'a')
                    return State::AOdd;

                if (character == 'b')
                    return State::BOdd;

                return State::Error;
            }

            case State::BOdd:
            {
                if (character == 'b')
                    return State::BEven;

                return State::Error;
            }

            case State::BEven:
            {
                if (character == 'b')
                    return State::BOdd;

                if (character == 'c')
                    return State::CMod1;

                return State::Error;
            }

            case State::CMod1:
            {
                if (character == 'c')
                    return State::CMod2;

                return State::Error;
            }

            case State::CMod2:
            {
                if (character == 'c')
                    return State::CMod0;

                return State::Error;
            }

            case State::CMod0:
            {
                if (character == 'c')
                    return State::CMod1;

                return State::Error;
            }

            case State::Error:
                return State::Error;
        }

        return State::Error;
    }

    bool IsAcceptingState(State state) const
    {
        return state == State::CMod0;
    }
};

int main()
{
    FiniteAutomaton automaton;
    std::string word;

    std::cout << "Enter word: ";
    std::cin >> word;

    if (automaton.Recognize(word))
        std::cout << "Word belongs to the language.\n";
    else
        std::cout << "Word does not belong to the language.\n";

    return 0;
}
```
